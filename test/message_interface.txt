Разработка интерфейса для обмена сообщениями между пользователями.
Основные элементы:
* Текстовое поле для ввода сообщений (с поддержкой форматирования текста).
* Кнопка 'Отправить'
* Список переписки (отображение истории сообщений с возможностью сортировки и фильтрации).
* Отображение статуса отправки сообщения (отправлено, доставлено, прочитано).
* Возможность прикрепления файлов к сообщениям (опционально).  Необходимо предусмотреть ограничение на размер файла.
