Системный промпт с инструментами всегда остаётся в контексте и не сжимается. Режим «Последние N сообщений» считает только реплики пользователя и ассистента (записи инструментов остаются при своём ходе). Sliding Window — жёсткое окно: хранятся последние N записей истории любого типа (включая вызовы инструментов), всё старое отбрасывается; окно может начаться с середины хода. Sticky Facts — агент извлекает из диалога факты ключ-значение (отдельным вызовом LLM без контекста), хранит их в БД и подмешивает в контекст вместе с последними N сообщениями; консолидация (M > 0) периодически сливает дубли фактов. В режиме summary старая часть диалога заменяется кратким содержанием, которое обновляется через каждые M сообщений.

Инструменты агента: системное время, список файлов, чтение, запись, дописывание, удаление файлов (test/), калькулятор. Запись и удаление требуют вашего подтверждения.

Диалог
Наведите на своё сообщение — справа на полях появится иконка ветвления: она создаёт ветку диалога с этого места (вкладка над чатом). Вкладка переименовывается двойным кликом.
Скрипт диалога
JSON: список диалогов, у каждого — название, свои настройки и сообщения пользователя. Диалоги выполняются по очереди, каждый получает вкладку над чатом (все остаются доступны после прогона). Сравнительная таблица показывается на вкладке диалога, из которого запущен скрипт.
